🔥 X Fresh Feed Tracker

Tracks very fresh posts on x.com. Recommended: a dedicated tracking account that follows only the accounts you want — then its x.com/home feed is already your watchlist.

Leave empty = all authors in the feed (freshness filter only).
Older posts are ignored. For “just now”, set e.g. 5 minutes.
X does not always refresh itself. 60–120 s keeps the feed fresh (tab must stay open).

Telegram forwarding (English)

Add your bot to the group and make it admin. Get the chat id (e.g. via @userinfobot or the bot’s getUpdates).

Live API (local)

The extension POSTs new posts to <url>/ingest. The API serves GET <url>/feed (JSON). Start it with: python3 api_server.py
